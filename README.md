## 🌿 About

**MannSathi** (मन का साथी — *Companion of the Mind*) is a culturally sensitive mental health platform built for India. It bridges the gap between traditional stigma around mental health and modern clinical care by combining AI-driven empathy with professional therapy — in the languages and cultural context Indians relate to.

Whether you are dealing with stress, anxiety, relationship struggles, or a deeper crisis, MannSathi is here — judgment-free, 24/7, in Hindi, English, or Hinglish.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🤖 **AI Companion** | Gemini AI-powered conversational companion supporting Hindi, English, and Hinglish |
| 👨‍⚕️ **Verified Therapist Booking** | Connect with licensed psychologists with verified specializations (CBT, Trauma, Career Counseling, and more) |
| 🎭 **Anonymous Mode** | Seek help without revealing your identity — your privacy is protected |
| 📊 **Mood Tracking** | Daily emotional check-ins with visual mood trend charts |
| 🚨 **Crisis Detection** | Automatically detects distress, self-harm intent, or suicidal ideation and escalates to emergency support |
| 🌏 **Cultural Sensitivity** | Designed for Indian social and cultural context — not a western template |
| 💬 **Session Summaries** | AI-generated clinical session summaries to assist therapists in follow-up care |

## 🚀 Getting Started

**Prerequisites:** Node.js

```bash
git clone https://github.com/abhishekgautam95/ManSathi.git
cd ManSathi
npm install
# Add your Gemini API key to .env.local
# GEMINI_API_KEY=your_api_key_here
npm run dev
```

## 🛡️ Safety & Ethics

- **AI Disclaimer:** MannSathi's AI companion provides emotional support and is not a substitute for professional medical advice, diagnosis, or treatment.
- **Crisis Escalation:** The platform automatically detects signs of self-harm or suicidal intent and escalates to emergency helplines and crisis resources.
- **Professional Referral:** Users showing persistent distress are guided toward licensed therapists available on the platform.
- **Privacy First:** Anonymous mode ensures users can seek help without fear of stigma or exposure.
